# أصول بصرية

| الملف | الاستخدام |
|-------|-----------|
| `../../web/static/img/logo.svg` | الشعار الكامل (رأس لوحة التحكم، README) |
| `../../web/static/img/logo-mark.svg` | العلامة المربعة (أفاتار، أيقونة تطبيق) |
| `../../web/static/img/favicon.svg` | أيقونة المتصفح |
| `../../web/static/img/architecture.svg` | مخطط معمارية العقل (README وبطاقة المعلومات) |
| `social-preview.html` | بطاقة المعاينة الاجتماعية 1200×630 (ولّدت كـ `social-preview.png`) |

لإعادة توليد صورة المعاينة بعد تعديل الـ HTML:

```bash
python3 docs/assets/render_social.py
```
